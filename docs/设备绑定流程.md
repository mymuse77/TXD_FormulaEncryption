# 设备绑定功能使用流程

## 概述

设备绑定是一种软件保护机制，通过将DLL插件与特定计算机的硬件信息绑定，防止未授权复制使用。只有经过授权的机器才能正常运行插件。

### 📌 第一步：开发者配置

#### 1.1 修改配置文件

编辑 `config.json`，启用设备绑定：

```json
{
  "pluginName": "MyTdxPlugin",
  "pluginDescription": "我的通达信公式插件",
  "functions": [
    {
      "id": 1,
      "name": "MyMA",
      "description": "自定义N日均线",
      "formulaType": "MA",
      "parameters": [
        {
          "name": "period",
          "defaultValue": 10,
          "description": "均线周期"
        }
      ]
    }
  ],
  "security": {
    "enableTimeLimit": false,
    "expireYear": 2026,
    "enableDeviceBinding": true,      // ← 启用设备绑定
    "enableOnlineVerify": false,
    "verifyUrl": null
  }
}
```

#### 1.2 生成DLL

运行生成器：

```bash
TdxDllGenerator generate -c config.json -o ./output
```

生成的文件将包含设备验证代码：

```cpp
// MyTdxPlugin.cpp 中自动生成的验证代码
bool CheckMachineID()
{
    char currentFingerprint[32];
    GenerateMachineFingerprint(currentFingerprint, sizeof(currentFingerprint));
    
    // 读取授权文件中的指纹
    char authorizedFingerprint[32];
    if (!LoadLicenseFile(authorizedFingerprint)) {
        return false;  // 无授权文件，验证失败
    }
    
    return strcmp(currentFingerprint, authorizedFingerprint) == 0;
}

BOOL RegisterTdxFunc(PluginTCalcFuncInfo** pFun)
{
    // 检查设备绑定
    if (!CheckMachineID()) {
        // 验证失败，可以弹出提示
        MessageBoxA(NULL, 
            "设备未授权！\n请联系开发者获取授权。\n\n机器指纹：xxx", 
            "授权失败", 
            MB_OK | MB_ICONERROR);
        return FALSE;
    }
    
    *pFun = g_CalcFuncSets;
    return TRUE;
}
```

### 📌 第二步：创建指纹生成工具

开发者需要创建一个独立的工具程序，用于在用户机器上生成机器指纹。

#### 2.1 指纹生成工具代码

创建 `MachineIDGenerator.cpp`：

```cpp
#include <windows.h>
#include <stdio.h>
#include <wbemidl.h>
#include <iphlpapi.h>

#pragma comment(lib, "wbemuuid.lib")
#pragma comment(lib, "iphlpapi.lib")

// 获取硬盘序列号
bool GetDiskSerialNumber(char* serial, int maxLen)
{
    CoInitialize(NULL);
    
    IWbemLocator* pLoc = NULL;
    HRESULT hr = CoCreateInstance(CLSID_WbemLocator, 0, CLSCTX_INPROC_SERVER,
                                  IID_IWbemLocator, (LPVOID*)&pLoc);
    
    if (FAILED(hr)) {
        CoUninitialize();
        return false;
    }
    
    IWbemServices* pSvc = NULL;
    hr = pLoc->ConnectServer(
        _bstr_t(L"ROOT\\CIMV2"),
        NULL, NULL, 0, NULL, 0, 0, &pSvc);
    
    if (FAILED(hr)) {
        pLoc->Release();
        CoUninitialize();
        return false;
    }
    
    IEnumWbemClassObject* pEnumerator = NULL;
    hr = pSvc->ExecQuery(
        bstr_t("WQL"),
        bstr_t("SELECT SerialNumber FROM Win32_DiskDrive"),
        WBEM_FLAG_FORWARD_ONLY | WBEM_FLAG_RETURN_IMMEDIATELY,
        NULL, &pEnumerator);
    
    if (SUCCEEDED(hr) && pEnumerator) {
        IWbemClassObject* pclsObj = NULL;
        ULONG uReturn = 0;
        hr = pEnumerator->Next(WBEM_INFINITE, 1, &pclsObj, &uReturn);
        if (SUCCEEDED(hr) && uReturn > 0 && pclsObj) {
            VARIANT vtProp;
            hr = pclsObj->Get(L"SerialNumber", 0, &vtProp, 0, 0);
            if (SUCCEEDED(hr)) {
                WideCharToMultiByte(CP_ACP, 0, vtProp.bstrVal, -1, 
                                   serial, maxLen, NULL, NULL);
                VariantClear(&vtProp);
            }
            pclsObj->Release();
        }
        pEnumerator->Release();
    }
    
    pSvc->Release();
    pLoc->Release();
    CoUninitialize();
    
    return strlen(serial) > 0;
}

// 获取MAC地址
bool GetMacAddress(unsigned char* mac)
{
    PIP_ADAPTER_INFO pAdapterInfo = (IP_ADAPTER_INFO*)malloc(sizeof(IP_ADAPTER_INFO));
    ULONG ulOutBufLen = sizeof(IP_ADAPTER_INFO);
    
    if (GetAdaptersInfo(pAdapterInfo, &ulOutBufLen) == ERROR_BUFFER_OVERFLOW) {
        free(pAdapterInfo);
        pAdapterInfo = (IP_ADAPTER_INFO*)malloc(ulOutBufLen);
    }
    
    if (GetAdaptersInfo(pAdapterInfo, &ulOutBufLen) == NO_ERROR) {
        PIP_ADAPTER_INFO pAdapter = pAdapterInfo;
        while (pAdapter) {
            if (pAdapter->Type == MIB_IF_TYPE_ETHERNET && 
                pAdapter->AddressLength == 6) {
                memcpy(mac, pAdapter->Address, 6);
                free(pAdapterInfo);
                return true;
            }
            pAdapter = pAdapter->Next;
        }
    }
    
    free(pAdapterInfo);
    return false;
}

// 生成机器指纹
void GenerateMachineFingerprint(char* fingerprint, int maxLen)
{
    char diskSerial[256] = {0};
    unsigned char mac[6] = {0};
    
    GetDiskSerialNumber(diskSerial, sizeof(diskSerial));
    GetMacAddress(mac);
    
    // 组合硬件信息
    char hardwareInfo[512];
    sprintf_s(hardwareInfo, sizeof(hardwareInfo), 
              "%s-%02X%02X%02X%02X%02X%02X",
              diskSerial,
              mac[0], mac[1], mac[2], mac[3], mac[4], mac[5]);
    
    // 简化版哈希（实际使用SHA256）
    unsigned int hash = 0;
    for (int i = 0; i < strlen(hardwareInfo); i++) {
        hash = hash * 31 + hardwareInfo[i];
    }
    
    // 生成16位指纹
    sprintf_s(fingerprint, maxLen, "%08X%08X", hash, hash ^ 0xAAAAAAAA);
}

int main()
{
    printf("========================================\n");
    printf("  通达信DLL插件 - 机器指纹生成工具\n");
    printf("========================================\n\n");
    
    char fingerprint[64];
    GenerateMachineFingerprint(fingerprint, sizeof(fingerprint));
    
    printf("您的机器指纹：\n");
    printf("\n");
    printf("  %s\n", fingerprint);
    printf("\n");
    printf("========================================\n");
    printf("请将此指纹发送给开发者以获取授权。\n");
    printf("========================================\n\n");
    
    // 自动复制到剪贴板
    if (OpenClipboard(NULL)) {
        EmptyClipboard();
        HGLOBAL hMem = GlobalAlloc(GMEM_MOVEABLE, strlen(fingerprint) + 1);
        if (hMem) {
            memcpy(GlobalLock(hMem), fingerprint, strlen(fingerprint) + 1);
            GlobalUnlock(hMem);
            SetClipboardData(CF_TEXT, hMem);
        }
        CloseClipboard();
        printf("（指纹已自动复制到剪贴板，可直接粘贴）\n\n");
    }
    
    system("pause");
    return 0;
}
```

#### 2.2 编译指纹生成工具

```bash

```

### 📌 第三步：用户使用流程

#### 3.1 获取机器指纹

**用户操作：**
1. 从开发者处获取 `MachineIDGenerator.exe`
2. 在需要安装DLL的电脑上运行该程序
3. 程序显示机器指纹（如：`A1B2C3D4E5F67890`）
4. 将指纹通过邮件/微信发送给开发者

**示例界面：**
```
========================================
  通达信DLL插件 - 机器指纹生成工具
========================================

您的机器指纹：

  A1B2C3D4E5F67890

========================================
请将此指纹发送给开发者以获取授权。
========================================

（指纹已自动复制到剪贴板，可直接粘贴）

请按任意键继续...
```

#### 3.2 开发者生成授权

**开发者收到机器指纹后：**

创建授权文件 `license.dat`：

```json
{
  "license": {
    "version": "1.0",
    "user": "张三",
    "email": "zhangsan@example.com",
    "machineFingerprint": "A1B2C3D4E5F67890",
    "issueDate": "2024-03-10",
    "expireDate": "2025-03-10",
    "maxDevices": 1,
    "features": ["MA", "EMA", "RSI"]
  },
  "signature": "MEUCIQDT2Z8..."  // RSA签名（可选）
}
```

#### 3.3 用户安装授权

**用户操作：**
1. 从开发者处获取：
   - `MyTdxPlugin.dll`（主程序）
   - `license.dat`（授权文件）

2. 将两个文件复制到通达信目录：
   ```
   C:\new_tdx64\T0002\dlls\
   ├── MyTdxPlugin.dll
   └── license.dat
   ```

3. 在通达信中绑定DLL（按正常流程）

### 📌 第四步：验证流程

#### 4.1 正常情况

DLL加载时自动验证：
```
1. 通达信加载 MyTdxPlugin.dll
2. 调用 RegisterTdxFunc()
3. CheckMachineID() 读取 license.dat
4. 比对当前机器指纹和授权指纹
5. 匹配 → 返回 TRUE，DLL正常使用
```

#### 4.2 异常情况

**场景1：无授权文件**
```
错误提示："未找到授权文件 license.dat，请联系开发者获取授权。"
```

**场景2：指纹不匹配（换机器）**
```
错误提示："设备未授权！当前机器指纹：B2C3D4E5F6G78901，
          授权指纹：A1B2C3D4E5F67890。
          请联系开发者重新授权。"
```

**场景3：授权过期**
```
错误提示："授权已过期（2025-03-10），请联系开发者续期。"
```

## 常见问题

### Q1: 用户重装系统后还能用吗？

**答：** 取决于硬件是否变化。
- 如果只重装系统，硬件不变 → 指纹不变，可用
- 如果更换硬盘/网卡 → 指纹改变，需重新授权

### Q2: 如何支持多设备？

**答：** 两种方案：
1. **多份授权**：为每台设备生成独立的 license.dat
2. **批量授权**：在授权文件中存储多个指纹

```json
{
  "license": {
    "maxDevices": 3,
    "machineFingerprints": [
      "A1B2C3D4E5F67890",
      "B2C3D4E5F6G78901",
      "C3D4E5F6G7H89012"
    ]
  }
}
```

### Q3: 如何防止用户复制授权文件？

**答：** 
1. 授权文件与DLL文件绑定（校验哈希）
2. 授权文件加密存储
3. 定期在线验证
4. 授权文件包含用户身份信息

### Q4: 虚拟机环境如何处理？

**答：**
- 可以检测虚拟机并拒绝运行
- 或单独提供虚拟机授权（价格更高）
- 代码示例：

```cpp
bool IsVirtualMachine()
{
    // 检测常见虚拟机特征
    // VMware, VirtualBox, Hyper-V等
    return CheckVMRegistryKeys() || CheckVMProcesses();
}
```

## 注意事项

### 开发者注意事项

1. **隐私合规**
   - 明确告知用户会收集硬件信息
   - 仅用于授权验证，不作他用
   - 遵守数据保护法规

2. **稳定性保障**
   - 提供备用授权机制（如紧急授权码）
   - 处理硬件更换场景（如硬盘损坏）
   - 保留人工客服渠道

3. **安全防护**
   - 授权文件加密
   - 防止DLL被篡改
   - 定期更新验证算法

### 用户注意事项

1. **备份授权**
   - 妥善保存 license.dat 文件
   - 重装系统前先记录指纹

2. **硬件更换**
   - 更换硬盘/网卡前联系开发者
   - 可能需要重新授权

3. **防骗提示**
   - 只从官方渠道获取授权
   - 不要分享授权文件给他人

## 总结

设备绑定的完整流程：

```
1. 开发者：启用设备绑定 → 生成DLL + 指纹工具
2. 用户：运行指纹工具 → 发送指纹给开发者
3. 开发者：生成授权文件 → 发送给用户
4. 用户：放置DLL + 授权文件 → 正常使用
```

**核心优势：**
- ✅ 一机一码，防止复制
- ✅ 无需网络，离线验证
- ✅ 灵活控制，可设置有效期
- ✅ 硬件级绑定，难以破解

**使用成本：**
- 开发者：需管理授权文件
- 用户：换机需重新申请授权
