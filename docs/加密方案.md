# 通达信DLL加密方案文档

## 概述

本文档介绍通达信DLL插件的安全保护方案，包括时间限制、设备绑定、网络验证等多层防护机制。

## 安全级别

| 级别 | 功能 | 适用场景 |
|------|------|----------|
| 基础 | 时间限制 | 个人用户 |
| 标准 | 时间 + 设备绑定 | 商业产品 |
| 高级 | 全部 + 网络验证 | 高端产品 |

## 一、时间限制

### 配置
```json
{
  "security": {
    "enableTimeLimit": true,
    "expireYear": 2025
  }
}
```

### 实现原理
```cpp
bool CheckExpiration()
{
    SYSTEMTIME st;
    GetSystemTime(&st);
    return (st.wYear < expireYear);
}
```

### 防篡改技巧
- 多重时间源验证（系统时间 + 文件时间）
- 隐藏检查点（分散到算法函数中）

## 二、设备绑定

### 配置
```json
{
  "security": {
    "enableDeviceBinding": true
  }
}
```

### 实现原理
1. 读取硬件信息（硬盘序列号、MAC地址）
2. 生成机器指纹（SHA256哈希）
3. 与授权码比对验证

### 机器指纹生成
```cpp
void GenerateFingerprint(char* fingerprint)
{
    char diskSerial[256], mac[6];
    GetDiskSerialNumber(diskSerial);
    GetMacAddress(mac);
    
    // SHA256(diskSerial + mac)
    SHA256(hash, diskSerial + mac);
    
    // 取前16位作为指纹
    strncpy(fingerprint, hash, 16);
}
```

## 三、网络验证

### 配置
```json
{
  "security": {
    "enableOnlineVerify": true,
    "verifyUrl": "https://your-server.com/api/verify"
  }
}
```

### 实现原理
1. DLL启动时向服务器发送验证请求
2. 服务器返回授权状态
3. 支持远程吊销授权

### HTTP请求示例
```cpp
bool OnlineVerify()
{
    // 使用WinHTTP发送POST请求
    // machineId + token
    // 返回: {status: "active" | "expired" | "revoked"}
}
```

## 四、代码保护

### 1. 控制流扁平化
混淆算法逻辑，增加逆向难度。

### 2. 字符串加密
敏感字符串编译时加密，运行时解密。

### 3. 反调试
检测调试器，发现后终止运行。

## 五、部署建议

### 实施步骤
1. 配置安全选项（config.json）
2. 生成机器指纹工具
3. 搭建授权服务器（如需网络验证）
4. 编译DLL（Release + 静态链接）
5. 测试验证（正常/过期/换设备）
6. 部署到用户机器

### 注意事项
- 隐私合规：收集硬件信息需告知用户
- 稳定性：保留离线容错机制
- 可维护性：保留紧急解锁通道

## 附录

### 推荐加密算法
- 哈希：SHA-256
- 对称加密：AES-256
- 非对称加密：RSA-2048
- 校验：HMAC-SHA256

建议每季度：
1. 更新加密密钥
2. 检查新漏洞
3. 升级安全机制
