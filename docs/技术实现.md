## 核心技术

### 1. 插件接口规范

#### 1.1 核心数据结构

```cpp
#pragma pack(push, 1)  // 按1字节对齐，确保跨平台兼容

// 函数指针类型定义
// 参数：数据长度、输出数组、输入A、输入B、输入C
typedef void(*pPluginFUNC)(int, float*, float*, float*, float*);

// 函数信息结构体
typedef struct tagPluginTCalcFuncInfo {
    unsigned short nFuncMark;  // 函数编号（1-65535）
    pPluginFUNC    pCallFunc;  // 函数指针
} PluginTCalcFuncInfo;

#pragma pack(pop)
```

**技术要点：**
- `#pragma pack(push, 1)` 确保结构体内存紧凑布局
- `unsigned short` 占用2字节，支持最多65535个函数
- 函数指针严格遵循通达信定义的签名

#### 1.2 入口函数

```cpp
extern "C" __declspec(dllexport) 
BOOL RegisterTdxFunc(PluginTCalcFuncInfo** pFun)
```

**执行流程：**
1. 通达信启动时扫描 `T0002\dlls\` 目录
2. 调用 `LoadLibrary()` 加载DLL
3. 通过 `GetProcAddress()` 获取 `RegisterTdxFunc` 地址
4. 调用 `RegisterTdxFunc(&pFuncTable)` 获取函数表
5. 根据函数ID调用具体算法

### 2. 技术指标算法实现

#### 2.1 移动平均线 (MA)

**数学公式：**
$$
MA_n = \frac{1}{n} \sum_{i=0}^{n-1} Close_{t-i}
$$

**C++实现：**
```cpp
void MyMA(int nDataLen, float* pfOut, float* pfIn1, float* pfIn2, float* pfIn3)
{
    int nPeriod = (int)pfIn2[0];  // 从参数2获取周期
    if (nPeriod <= 0) nPeriod = 10; // 默认10日
    
    for (int i = 0; i < nDataLen; i++) {
        float sum = 0;
        int count = 0;
        // 累加前n个周期的收盘价
        for (int j = i; j >= 0 && j > i - nPeriod; j--) {
            sum += pfIn1[j];
            count++;
        }
        pfOut[i] = (count > 0) ? sum / count : 0;
    }
}
```

**算法复杂度：**
- 时间复杂度：O(n × m)，n为数据长度，m为周期
- 空间复杂度：O(1)，仅使用临时变量

#### 2.2 指数移动平均 (EMA)

**数学公式：**
$$
EMA_t = \alpha \times Close_t + (1-\alpha) \times EMA_{t-1}
$$
其中平滑系数 $\alpha = \frac{2}{n+1}$

**C++实现：**
```cpp
void MyEMA(int nDataLen, float* pfOut, float* pfIn1, float* pfIn2, float* pfIn3)
{
    int nPeriod = (int)pfIn2[0];
    if (nPeriod <= 0) nPeriod = 12;
    float alpha = 2.0f / (nPeriod + 1);  // 计算平滑系数
    
    if (nDataLen > 0) {
        pfOut[0] = pfIn1[0];  // 首日EMA等于收盘价
        for (int i = 1; i < nDataLen; i++) {
            pfOut[i] = alpha * pfIn1[i] + (1 - alpha) * pfOut[i - 1];
        }
    }
}
```

**特点：**
- 递归计算，当前值依赖前一值
- 对近期价格赋予更高权重
- 响应速度比MA快

#### 2.3 相对强弱指标 (RSI)

**数学公式：**
$$
RSI = 100 - \frac{100}{1 + RS}
$$
其中 $RS = \frac{\text{平均涨幅}}{\text{平均跌幅}}$

**C++实现：**
```cpp
void MyRSI(int nDataLen, float* pfOut, float* pfIn1, float* pfIn2, float* pfIn3)
{
    int nPeriod = (int)pfIn2[0];
    if (nPeriod <= 0) nPeriod = 14;
    
    for (int i = nPeriod; i < nDataLen; i++) {
        float gain = 0, loss = 0;
        // 计算n周期内的涨跌
        for (int j = i - nPeriod + 1; j <= i; j++) {
            float change = pfIn1[j] - pfIn1[j - 1];
            if (change > 0) gain += change;
            else loss -= change;  // loss为正值
        }
        float avgGain = gain / nPeriod;
        float avgLoss = loss / nPeriod;
        
        if (avgLoss == 0) pfOut[i] = 100;
        else pfOut[i] = 100 - (100 / (1 + avgGain / avgLoss));
    }
}
```

**技术细节：**
- 前n-1个数据无法计算，输出保持原值
- 使用简单平均法（非Wilder平滑）
- 返回值范围：0-100

### 3. 内存管理

#### 3.1 数据缓冲区

通达信为每个函数调用分配三个输入缓冲区和一个输出缓冲区：

```
pfIn1:  输入数据A（通常是CLOSE）
pfIn2:  输入数据B（通常是参数，如周期）
pfIn3:  输入数据C（保留）
pfOut:  输出结果缓冲区（与数据等长）
```

**内存安全：**
- 数组索引范围：`[0, nDataLen-1]`
- 通达信保证缓冲区已分配且对齐
- 插件无需分配/释放内存

#### 3.2 多线程安全

```cpp
// DLL主入口函数
BOOL APIENTRY DllMain(HMODULE hModule, DWORD ul_reason_for_call, LPVOID lpReserved)
{
    switch (ul_reason_for_call) {
    case DLL_PROCESS_ATTACH:
        DisableThreadLibraryCalls(hModule);  // 禁用线程通知，提高性能
        break;
    // ...
    }
    return TRUE;
}
```

**线程模型：**
- 通达信在主线程调用DLL函数
- 每个股票代码独立计算
- 无共享状态，天然线程安全

## 接口规范

### 函数调用约定

通达信使用 `__cdecl` 调用约定调用DLL函数：

| 参数 | 类型 | 方向 | 说明 |
|------|------|------|------|
| nDataLen | int | in | 数据长度（K线数量） |
| pfOut | float* | out | 输出数组，长度nDataLen |
| pfIn1 | float* | in | 输入数组A |
| pfIn2 | float* | in | 输入数组B（参数） |
| pfIn3 | float* | in | 输入数组C（保留） |

### 公式调用语法

```
TDXDLL{n}(FuncID, Data1, Data2, Data3)
```

**参数映射：**
- `Data1` → `pfIn1`
- `Data2` → `pfIn2[0]`（注意：只取第一个值）
- `Data3` → `pfIn3`（通常不用）

**示例：**
```
MA10: TDXDLL10(1, CLOSE, 10, 0);
     // FuncID=1, pfIn1=CLOSE数组, pfIn2[0]=10
```

## 数据流

### 计算流程

```
通达信公式解析
      │
      ▼
检测到TDXDLLn()函数
      │
      ▼
查找已绑定的DLL (n=1~10)
      │
      ▼
调用RegisterTdxFunc获取函数表
      │
      ▼
根据FuncID查找函数指针
      │
      ▼
准备数据缓冲区
      │
      ▼
调用算法函数
      │
      ▼
返回结果到pfOut
      │
      ▼
通达信绘制指标
```

### 数据对齐

通达信保证：
- 所有数组起始地址32字节对齐
- 数据按时间顺序排列（旧→新）
- 无NaN或无效数据

## 性能优化

### 1. 算法优化

**循环展开示例：**
```cpp
// 原始代码
for (int i = 0; i < n; i++) sum += data[i];

// 优化后 - 4路展开
for (int i = 0; i < n - 3; i += 4) {
    sum += data[i] + data[i+1] + data[i+2] + data[i+3];
}
for (; i < n; i++) sum += data[i];
```

### 2. 缓存优化

- **空间局部性**：顺序访问数组，利用CPU缓存行
- **时间局部性**：避免重复计算相同值
- **预取**：编译器自动优化

### 3. 精度优化

```cpp
// 使用float而非double（4字节 vs 8字节）
// 减少内存带宽，提高缓存命中率
void MyFunc(int n, float* out, float* in);  // ✅
void MyFunc(int n, double* out, double* in); // ❌ 不必要
```

| MA(10) | 5000条K线 | ~0.1ms |
| EMA(12) | 5000条K线 | ~0.05ms |

### 3. 常见问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 绑定失败 | 架构不匹配 | 32位通达信用Win32 DLL，64位用x64 DLL |
| 计算结果为0 | 数组越界 | 检查循环索引范围 |
| 数据异常 | 未初始化 | 前n个周期数据无效是正常的 |
| 崩溃 | 空指针 | 检查nDataLen > 0 |
