# 通达信DLL插件使用说明

## 📋 快速开始（3分钟上手）

### Step 1: 准备环境

**确认通达信版本：**
- 打开通达信安装目录
- 如果路径包含 `x64` 或 `64`（如 `C:\new_tdx64`）→ **64位版本**
- 如果路径是普通名称（如 `C:\tdx`）→ **32位版本**

### Step 2: 获取DLL文件

**从开发者处获取：**
```
MyTdxPlugin.dll  ← 主程序文件
```

**确认文件架构：**
```bash
# 使用dumpbin检查（开发者提供）
dumpbin /headers MyTdxPlugin.dll | findstr "machine"
# x86 = 32位, x64 = 64位
```

### Step 3: 复制到通达信目录

**复制DLL文件：**
```
源文件：MyTdxPlugin.dll
目标目录：C:\new_tdx64\T0002\dlls\
          └─ 通达信安装目录\T0002\dlls\
```

> ⚠️ **注意**：如果 `dlls` 文件夹不存在，请手动创建

### Step 4: 在通达信中绑定DLL

**操作步骤：**

1. **打开公式管理器**
   - 按 `Ctrl + F`
   - 或点击菜单【功能】→【公式管理器】

2. **进入DLL函数绑定**
   - 点击【DLL函数】按钮

3. **选择DLL编号**
   - 从下拉列表选择编号（如：第10号DLL）
   - 编号对应公式中的 `TDXDLL10`

4. **绑定DLL文件**
   - 点击【打开绑定】按钮
   - 在文件浏览器中选择 `MyTdxPlugin.dll`
   - 点击【确定】

5. **验证绑定成功**
   - 看到"绑定成功"提示即完成
   - 如遇"绑定失败"，检查DLL架构是否匹配

## 🔧 详细使用指南

### 一、在公式中调用DLL函数

#### 基本语法

```tdx
TDXDLL{n}(FuncID, 数据, 参数, 0)
```

| 参数 | 说明 | 示例 |
|------|------|------|
| `n` | DLL编号（1-10） | `TDXDLL10` 表示第10号DLL |
| `FuncID` | 函数ID（1,2,3...） | `1`=MA, `2`=EMA, `3`=RSI |
| `数据` | 输入数据序列 | `CLOSE`（收盘价） |
| `参数` | 周期参数 | `10`（10日） |
| `0` | 保留参数 | 固定为0 |

#### 完整示例

```tdx
{==========================================}
{  示例1：绘制5日均线 }
{==========================================}
MA5: TDXDLL10(1, CLOSE, 5, 0);

{==========================================}
{  示例2：绘制10日均线 }
{==========================================}
MA10: TDXDLL10(1, CLOSE, 10, 0);

{==========================================}
{  示例3：绘制20日均线 }
{==========================================}
MA20: TDXDLL10(1, CLOSE, 20, 0);

{==========================================}
{  示例4：绘制60日均线（季线）}
{==========================================}
MA60: TDXDLL10(1, CLOSE, 60, 0);

{==========================================}
{  示例5：绘制12日EMA }
{==========================================}
EMA12: TDXDLL10(2, CLOSE, 12, 0);

{==========================================}
{  示例6：绘制26日EMA }
{==========================================}
EMA26: TDXDLL10(2, CLOSE, 26, 0);

{==========================================}
{  示例7：绘制14日RSI }
{==========================================}
RSI14: TDXDLL10(3, CLOSE, 14, 0);

{==========================================}
{  示例8：绘制6日RSI（更敏感）}
{==========================================}
RSI6: TDXDLL10(3, CLOSE, 6, 0);
```

### 二、创建完整技术指标公式

#### 1. 均线系统（主图叠加）

**新建公式：**
- 类型：【技术指标】→【主图指标】
- 名称：`我的均线`

```tdx
{==========================================}
{  均线系统 - 主图指标 }
{==========================================}

{短期均线}
MA5: TDXDLL10(1, CLOSE, 5, 0), COLORWHITE;
MA10: TDXDLL10(1, CLOSE, 10, 0), COLORYELLOW;

{中期均线}
MA20: TDXDLL10(1, CLOSE, 20, 0), COLORMAGENTA;
MA30: TDXDLL10(1, CLOSE, 30, 0), COLORCYAN;

{长期均线}
MA60: TDXDLL10(1, CLOSE, 60, 0), COLORGREEN;
MA120: TDXDLL10(1, CLOSE, 120, 0), COLORBLUE;

{==========================================}
{  均线交叉信号 }
{==========================================}
{金叉：5日线上穿10日线}
金叉: CROSS(MA5, MA10), NODRAW;
DRAWICON(金叉, LOW * 0.98, 1);  {在最低价附近画买入图标}

{死叉：5日线下穿10日线}
死叉: CROSS(MA10, MA5), NODRAW;
DRAWICON(死叉, HIGH * 1.02, 2);  {在最高价附近画卖出图标}
```

**使用效果：**
- 在主图K线上叠加5/10/20/30/60/120日均线
- 金叉时显示买入信号图标
- 死叉时显示卖出信号图标

#### 2. MACD指标（副图）

**新建公式：**
- 类型：【技术指标】→【副图指标】
- 名称：`自定义MACD`

```tdx
{==========================================}
{  MACD指标 - 副图 }
{==========================================}

{计算EMA}
EMA12: TDXDLL10(2, CLOSE, 12, 0);
EMA26: TDXDLL10(2, CLOSE, 26, 0);

{DIF线：快EMA - 慢EMA}
DIF: EMA12 - EMA26, COLORWHITE;

{DEA线：DIF的9日EMA}
DEA: TDXDLL10(2, DIF, 9, 0), COLORYELLOW;

{MACD柱：(DIF-DEA)*2}
MACD: (DIF - DEA) * 2, COLORSTICK;

{==========================================}
{  金叉死叉信号 }
{==========================================}
DIF金叉: CROSS(DIF, DEA), NODRAW;
DIF死叉: CROSS(DEA, DIF), NODRAW;

DRAWICON(DIF金叉, DEA, 1);
DRAWICON(DIF死叉, DEA, 2);

{==========================================}
{  零轴显示 }
{==========================================}
0, COLORGRAY, DOTLINE;
```

**使用效果：**
- 在副图显示DIF（白）、DEA（黄）、MACD柱（红绿）
- 金叉死叉自动标注图标
- 零轴参考线

#### 3. RSI交易系统（副图）

**新建公式：**
- 类型：【技术指标】→【副图指标】
- 名称：`RSI交易系统`

```tdx
{==========================================}
{  RSI交易系统 - 副图 }
{==========================================}

{RSI指标}
RSI6: TDXDLL10(3, CLOSE, 6, 0), COLORYELLOW;
RSI14: TDXDLL10(3, CLOSE, 14, 0), COLORWHITE;
RSI24: TDXDLL10(3, CLOSE, 24, 0), COLORMAGENTA;

{==========================================}
{  超买超卖线 }
{==========================================}
80, COLORRED, DOTLINE;    {超买线}
50, COLORGRAY, DOTLINE;   {强弱分界线}
20, COLORGREEN, DOTLINE;  {超卖线}

{==========================================}
{  交易信号 }
{==========================================}
{RSI从超卖区向上突破20}
买入信号: CROSS(RSI14, 20) AND REF(RSI14, 1) < 20, NODRAW;
DRAWTEXT(买入信号, 15, '买'), COLORRED;

{RSI从超买区向下跌破80}
卖出信号: CROSS(80, RSI14) AND REF(RSI14, 1) > 80, NODRAW;
DRAWTEXT(卖出信号, 85, '卖'), COLORGREEN;

{==========================================}
{  背离检测（简化版）}
{==========================================}
{价格创新高但RSI未创新高 - 顶背离}
顶背离: HIGH > REF(HIGH, 1) AND RSI14 < REF(RSI14, 1) AND RSI14 > 60, NODRAW;
DRAWTEXT(顶背离, 70, '顶背离'), COLORGREEN;

{价格创新低但RSI未创新低 - 底背离}
底背离: LOW < REF(LOW, 1) AND RSI14 > REF(RSI14, 1) AND RSI14 < 40, NODRAW;
DRAWTEXT(底背离, 30, '底背离'), COLORRED;
```

**使用效果：**
- 显示6/14/24日RSI
- 超买(80)/超卖(20)参考线
- 自动标记买卖信号
- 背离检测提醒

### 三、条件选股公式

#### 1. MA金叉选股

**新建公式：**
- 类型：【条件选股】
- 名称：`MA金叉选股`

```tdx
{==========================================}
{  MA金叉选股 }
{  选出5日线上穿10线的股票 }
{==========================================}

MA5: TDXDLL10(1, CLOSE, 5, 0);
MA10: TDXDLL10(1, CLOSE, 10, 0);

{金叉条件}
CROSS(MA5, MA10);

{可选：增加成交量确认}
{AND VOL > MA(VOL, 5) * 1.5;}
```

**使用方式：**
1. 按 `Ctrl + T` 打开条件选股
2. 选择 `MA金叉选股`
3. 设置选股范围（如：沪深A股）
4. 点击【执行选股】

## ❓ 常见问题解答

### Q1: 提示"绑定失败!此DLL装载失败"

**原因：**
- DLL架构与通达信不匹配（32位vs 64位）

**解决：**
1. 确认通达信版本（查看安装路径是否含`x64`）
2. 获取对应架构的DLL
3. 重新绑定

### Q2: 公式测试显示为空或0

**原因：**
1. DLL未正确绑定
2. 参数设置错误
3. 前n个周期数据无法计算

**解决：**
1. 检查DLL绑定状态
2. 确认函数ID和参数
3. 对于RSI等指标，前n个数据本来就是空的

### Q3: 如何更换绑定的DLL？

**步骤：**
1. 打开【DLL函数】对话框
2. 选择已绑定的DLL编号
3. 点击【解除绑定】
4. 重新【打开绑定】选择新DLL

### Q4: DLL函数可以在哪些公式类型中使用？

**支持：**
- ✅ 技术指标（主图/副图）
- ✅ 条件选股
- ✅ 预警系统
- ✅ K线模式
- ✅ 专家系统

**不支持：**
- ❌ 五彩K线（部分版本）

### Q5: 如何同时调用多个DLL？

**方法：**
- 每个DLL绑定到不同编号（如TDXDLL1, TDXDLL2...）
- 在公式中分别调用

```tdx
{DLL1绑定的是均线指标}
MA5: TDXDLL1(1, CLOSE, 5, 0);

{DLL2绑定的是动量指标}
MTM: TDXDLL2(1, CLOSE, 10, 0);
```

### Q6: 公式执行很慢怎么办？

**优化建议：**
1. 减少不必要的DLL调用
2. 缓存重复计算的结果
3. 使用本地计算替代部分DLL调用

```tdx
{优化前：每次调用都计算}
MA5: TDXDLL10(1, CLOSE, 5, 0);
MA5昨日: REF(TDXDLL10(1, CLOSE, 5, 0), 1);  {重复计算}

{优化后：先计算再引用}
MA5: TDXDLL10(1, CLOSE, 5, 0);
MA5昨日: REF(MA5, 1);  {直接使用已计算的值}
```
